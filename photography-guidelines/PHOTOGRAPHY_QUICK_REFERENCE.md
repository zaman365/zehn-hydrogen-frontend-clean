## 🎨 COMPOSITION GUIDELINES

### Product Photography Setup
```
        [BACK LIGHT]
              ↓
         ┌─────────┐
         │ PRODUCT │
         └─────────┘
       ↗           ↖
[FILL LIGHT]   [KEY LIGHT]
```

**Lighting:**
- 3-point lighting setup
- Color temp: 5500K (daylight)
- Soft shadows
- No blown highlights

**Framing:**
- Product: 70-80% of frame
- Padding: 10-15% margin
- Perfect center alignment
- Straight orientation

**Focus:**
- f/8 to f/11 (sharp throughout)
- Focus on center
- No motion blur

## ✅ PRE-DELIVERY CHECKLIST

### Technical Validation
- [ ] **Resolution:** Meets minimum dimensions
- [ ] **Aspect Ratio:** Correct for use case
- [ ] **Color Space:** sRGB embedded
- [ ] **File Size:** Within limits (Hero: 500KB, Product: 200KB)
- [ ] **Compression:** 85-90% quality
- [ ] **Format:** JPG for photos, PNG for transparency

### Composition Validation
- [ ] **Background:** Clean (white for products)
- [ ] **Lighting:** Consistent across set
- [ ] **Focus:** Sharp throughout
- [ ] **Framing:** Subject properly positioned
- [ ] **Safe Zones:** Critical elements protected
- [ ] **Orientation:** Correct (not rotated)

### Quality Validation
- [ ] **Color Accuracy:** Matches physical product
- [ ] **No Artifacts:** No compression artifacts
- [ ] **No Noise:** Clean image
- [ ] **Proper Exposure:** Not too dark/bright
- [ ] **White Balance:** Correct color temperature

## 🔧 COMMAND LINE TOOLS (Optional)

### Check Image Dimensions
```bash
identify -format "%f: %wx%h\n" *.jpg
```

### Check Color Space
```bash
identify -verbose image.jpg | grep Colorspace
```

### Batch Resize
```bash
mogrify -resize 1200x1200 -quality 90 *.jpg
```

### Convert to sRGB
```bash
mogrify -colorspace sRGB *.jpg
```

## 🚀 QUICK START WORKFLOW

1. **Setup:** 3-point lighting, white background, 5500K color temp
2. **Shoot:** Multiple angles, consistent framing, f/8-f/11
3. **Edit:** sRGB color space, proper exposure, white balance
4. **Resize:** Match specifications from table above
5. **Optimize:** 85-90% quality, check file size
6. **Name:** Follow naming convention
7. **Organize:** Place in correct folder
8. **Validate:** Run through checklist
9. **Deliver:** Upload to designated location

---

**Remember:** Consistency is key! All product images should have the same lighting, background, and composition style.
