## 🎯 Key Takeaways for Photographer

### Critical Requirements

#### 1. **Product Images (Most Important)**
```
Dimensions: 1200×1200px minimum
Aspect Ratio: 1:1 (Square)
Background: Pure White (#FFFFFF)
Lighting: Consistent 3-point setup
Views Required: Front, Back, Detail, Lifestyle
File Size: Max 200KB per image
```

**Each product needs:**
- ✅ Multiple color variants (separate images)
- ✅ Multiple angles (front, back, detail)
- ✅ Consistent lighting across all shots
- ✅ White background, no shadows
- ✅ Product centered with 10-15% padding

#### 2. **Hero Banners**
```
Desktop: 2400×1600px (3:2 landscape)
Mobile: 1200×1600px (3:4 portrait)
Text Area: Left 30% (keep clear)
File Size: Max 500KB
```

#### 3. **Category Tiles**
```
Dimensions: 1600×1600px (1:1 square)
Subject: Upper 2/3 of frame
Text Area: Lower 1/3 (dark gradient overlay)
File Size: Max 300KB
```

#### 4. **Bento Grid (Featured Section)**
```
Tall Portrait: 1200×1800px (2:3)
Wide Landscape: 1600×900px (16:9)
Square: 1200×1200px (1:1)
```

## 📸 Photography Setup

### Lighting Setup (3-Point)
```
        [BACK LIGHT]
              ↓
         ┌─────────┐
         │ PRODUCT │
         └─────────┘
       ↗           ↖
[FILL LIGHT]   [KEY LIGHT]
```

**Settings:**
- Color Temperature: 5500K (daylight)
- Aperture: f/8 to f/11 (sharp throughout)
- ISO: Lowest possible (100-200)
- Shutter: Based on lighting (no motion blur)

### Background
- Pure white seamless paper or cyclorama
- No texture, no wrinkles
- Consistent across all products

## 📁 File Delivery Format

### Naming Convention
```
[category]-[product-name]-[color]-[view].jpg

Examples:
polo-premium-cotton-navy-front.jpg
polo-premium-cotton-navy-back.jpg
polo-premium-cotton-white-front.jpg
cargo-tactical-khaki-front.jpg
```

### Folder Structure
```
/images
  /products
    /polo
      - polo-[name]-[color]-front.jpg
      - polo-[name]-[color]-back.jpg
      - polo-[name]-[color]-detail.jpg
    /cargo
    /chino
    /jacket
  /hero
  /categories
  /bento
  /banners
```

## 🚀 Workflow Summary

### 1. Pre-Production
- Review all 3 guideline documents
- Prepare lighting setup (3-point)
- Set up white background
- Calibrate camera (sRGB, 5500K)

### 2. Production
- Shoot all required angles per product
- Shoot all color variants
- Maintain consistent lighting
- Check focus and exposure
- Capture lifestyle shots

### 3. Post-Production
- Edit in sRGB color space
- Adjust white balance
- Crop to correct aspect ratios
- Resize to specified dimensions
- Optimize file size (85-90% quality)
- Apply proper naming convention

### 4. Quality Control
- Run through checklist
- Verify dimensions
- Check file sizes
- Confirm color accuracy
- Ensure consistency

### 5. Delivery
- Organize in folder structure
- Compress into archive (if needed)
- Upload to designated location
- Provide image inventory list

## 🔍 Common Mistakes to Avoid

### ❌ Don't Do This:
- Inconsistent lighting between products
- Shadows on white background
- Products not centered
- Wrong aspect ratios
- File sizes too large
- Incorrect color space (Adobe RGB instead of sRGB)
- Poor file naming (IMG_1234.jpg)
- Mixed backgrounds
- Blurry or out-of-focus images
- Over-compressed images

### ✅ Do This Instead:
- Consistent 3-point lighting setup
- Pure white background, no shadows
- Perfect center alignment
- Correct aspect ratios per spec
- Optimized file sizes (85-90% quality)
- sRGB color space
- Descriptive file names
- White background for all products
- Tack sharp focus (f/8-f/11)
- Proper compression balance
