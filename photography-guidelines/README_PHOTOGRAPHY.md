## 🎯 Critical Specifications Summary

### Product Images (Most Important)
```
Dimensions: 1200×1200px
Aspect Ratio: 1:1 (Square)
Background: Pure White (#FFFFFF)
File Size: Max 200KB
Format: JPG (85-90% quality)
Color Space: sRGB
```

### Hero Banners
```
Desktop: 2400×1600px (3:2)
Mobile: 1200×1600px (3:4)
File Size: Max 500KB
Format: JPG
```

### Category Tiles
```
Dimensions: 1600×1600px (1:1)
File Size: Max 300KB
Format: JPG
```

## 📸 Photography Setup Requirements

### Lighting
- 3-point lighting setup (key, fill, back)
- Color temperature: 5500K (daylight balanced)
- Soft, diffused light
- Minimal shadows

### Camera Settings
- Aperture: f/8 to f/11 (sharp throughout)
- ISO: Lowest possible (100-200)
- White Balance: 5500K or custom
- Color Space: sRGB
- Format: RAW + JPG (deliver JPG)

### Background
- Pure white seamless paper or cyclorama
- No texture, no wrinkles
- Consistent across all products

## 🎓 Best Practices

### Do's ✅
- Maintain consistent lighting throughout shoot
- Use pure white background for products
- Shoot in RAW format for flexibility
- Take multiple shots per setup
- Organize files as you go
- Back up regularly
- Follow naming convention strictly
- Check focus and exposure frequently

### Don'ts ❌
- Don't mix lighting setups
- Don't use colored backgrounds for products
- Don't over-compress images
- Don't skip color calibration
- Don't use incorrect color space
- Don't forget to shoot all angles
- Don't ignore file naming convention
- Don't deliver unorganized files
