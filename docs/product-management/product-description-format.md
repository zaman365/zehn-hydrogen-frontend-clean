# Product Description Format Guide

## Overview
Product descriptions support HTML formatting with bullet points and bold text for better readability.

## Recommended Format

Use this HTML structure in Shopify product description field:

```html
<ul>
<li><strong>Premium Baumwoll-Stretch:</strong> Atmungsaktiv, langlebig und extrem komfortabel mit 97% Baumwolle + 3% Elastan für optimale Bewegungsfreiheit</li>
<li><strong>Funktionale Taschen:</strong> Cargo- und Utility-Taschen sorgen dafür, dass alles sicher verstaut ist und schnell griffbereit bleibt</li>
<li><strong>Verstärkte und segmentierte Partien:</strong> Robuste Verarbeitung im Knie- und Oberschenkelbereich für einen dauerhaft formstabilen Look</li>
<li><strong>Vielseitiger Style:</strong> Perfekt für Urban-Explore, Office-Casual oder Travel-Outfits mit modernem, cleanen Design</li>
<li><strong>Regular Fit:</strong> Bequemer Begleiter für Alltag, Travel und Streetwear mit entspanntem Sitz ohne baggy zu wirken</li>
<li><strong>Passform-Tipp:</strong> Die Hose ist im Regular Fit geschnitten – wenn du zwischen zwei Größen liegst und einen cleaneren, schmaleren Look bevorzugst, wähle eher die kleinere Größe</li>
</ul>
```

## How to Add in Shopify

### Method 1: Using Shopify Rich Text Editor
1. Go to **Products** → Select product
2. In the **Description** field, click the **"Show HTML"** button (< > icon)
3. Paste the HTML code above
4. Click **Save**

### Method 2: Using Shopify Text Editor
1. Go to **Products** → Select product
2. Switch to **Text** mode (not Visual mode)
3. Paste the HTML code
4. Click **Save**

## Result on Website

The description will display as:
- **Premium Baumwoll-Stretch:** Atmungsaktiv, langlebig und extrem komfortabel...
- **Funktionale Taschen:** Cargo- und Utility-Taschen sorgen dafür...
- **Verstärkte und segmentierte Partien:** Robuste Verarbeitung...

## Template for Copy-Paste

```html
<ul>
<li><strong>Feature Title:</strong> Feature description text here</li>
<li><strong>Feature Title:</strong> Feature description text here</li>
<li><strong>Feature Title:</strong> Feature description text here</li>
</ul>
```

## Styling

The bullet points are automatically styled with:
- Disc bullets (•)
- Proper spacing between items
- Bold titles for emphasis
- Responsive text sizing

## Tips

- Keep titles short (2-4 words)
- Use colon (:) after the title
- Keep descriptions concise (1-2 sentences max)
- Use 4-8 bullet points per product
- Maintain consistent formatting across all products
