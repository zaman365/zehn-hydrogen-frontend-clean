# ZEHN Product Setup Guidelines

Complete guide for configuring products in Shopify for the ZEHN e-commerce platform.

---

## Required Product Fields

### Basic Information
- **Title**: Product name (max 70 characters)
- **Description**: 150-300 words with features and materials
- **Vendor**: Always `ZEHN`
- **Product Type**: Polo, Cargo, Chino, Jacket, Shirt, Pants
- **Tags**: `men`, `women`, `bestseller`, `new`, `sale`, `cotton`, etc.
- **SKU Format**: `ZEHN-[TYPE]-[COLOR]-[SIZE]` (e.g., `ZEHN-CARGO-BLK-32`)

---

## Image Requirements

### Technical Specs
- **Dimensions**: 2048x2048px (min 1200x1200px)
- **Format**: JPG (PNG for transparency)
- **Max Size**: 20MB
- **Count**: 4-8 images per product

### Image Types
Front view, back view, side view, detail shots, lifestyle (optional)

---

## Image Naming Convention

**CRITICAL**: Follow this exactly for automatic color filtering.

### Format
```
[product-slug]-[exact-color-name]-[number].jpg
```

### Examples
```
✅ polo-shirt-black-1.jpg          (Color: "Black")
✅ polo-shirt-navy-2.jpg            (Color: "Navy")
✅ shirt-forest-green-1.jpg         (Color: "Forest Green")
✅ chino-city-slate-2.jpg           (Color: "City Slate")
✅ polo-schwarz-1.jpg               (Color: "Schwarz")
```

### German-English Color Translations

The system automatically translates German colors:

| German Color | Matches Images With |
|--------------|---------------------|
| Schwarz | black, schwarz, slade |
| Blau | blue, blau |
| Grün | green, olive, grün |
| Grau | gray, grey, slate, slade, grau |

**Example**: Shopify variant "Schwarz" will show images with "black", "schwarz", or "slade" in filename.

### Alt Text Format
```
[Product Name] - [Color] - [View Type]

Examples:
- "Premium Polo Shirt - Navy - Front View"
- "Tactical Cargo Pants - Olive - Side View"
```

## Variant Structure

### Color Variants
- **Option Name**: "Color" or "Farbe"
- **Values**: Descriptive names (Navy, Forest Green, Heritage Blue, City Slate)
- Can use English, German, or compound names

### Size Variants
- **Option Name**: "Size" or "Größe"
- **Shirts/Tops**: XS, S, M, L, XL, XXL
- **Pants**: 28, 30, 32, 34, 36, 38, 40

### Color Swatches
Add hex code in variant settings:
- Navy: `#001f3f`
- Olive: `#556b2f`
- Black: `#000000`
- Heritage Blue: `#4a6fa5`
- City Slate: `#708090`

---

## SEO Requirements

**Meta Title**: `[Product Name] | ZEHN` (50-60 chars)

**Meta Description**: 150-160 chars with key features

**URL Handle**: `lowercase-with-hyphens`

**Structured Data**: Auto-generated by template

---

## Shopify Setup Steps

1. **Create Product** (5 min)
   - Add title, description, vendor, type, tags

2. **Upload Images** (5 min)
   - Rename files following convention
   - Upload with alt text

3. **Configure Variants** (5 min)
   - Add color and size options
   - Set price, SKU, inventory

4. **Add Color Swatches** (3 min)
   - Add hex codes for each color

5. **SEO Settings** (2 min)
   - Set meta title and description

6. **Save and Publish**

---

## Common Issues

| Issue | Solution |
|-------|----------|
| Images not filtering | Check filename matches color variant name |
| Swatches not showing | Add hex code to color variants |
| Wrong images for color | Remove extra color keywords from filename |
| Product not on storefront | Set status "Active", check inventory > 0 |
